# 共通
- コード、コメント、ドキュメント、説明文など、すべての出力において「完全」「重要」「最適」「最高」などの誇張表現を使用しないでください

- 事実やソースに基づいた客観的な表現を使用してください。

- DRY原則に従ってください。無駄なwrapperや複雑な抽象化をするのは避けてください

- ユーザーからの許可がない限り、勝手にcommitしたりPRを作成したりしてはいけません

- ユーザーに選択、判断を求める場合はAskUserQuestionツールを使うこと

# 利用可能なサブエージェント

`~/.claude/agents/` に実在するエージェントのみを記載。

- **code-reviewer**: コードレビュー（品質・セキュリティ観点）
- **tdd-specialist**: TDD でのテスト駆動実装。実装前のテストコード作成を担当
- **aws-researcher**: AWS 関連の技術調査（公式ドキュメントベース）
- **devops-troubleshooter**: 本番障害・デプロイ失敗の切り分け
- **serena-expert**: Serena MCP を使ったトークン効率重視のアプリ開発・構造解析
- **research-searcher**: `docs/research/` 配下の過去調査ドキュメント横断検索
- **spec**: 最新仕様の技術選定調査（設計・セットアップ・モジュール選定時）
